# Product photos

Drop one photo per product in this folder, named exactly as below. The site picks them up automatically; any product without a photo keeps its illustration.

| Product | File name |
| --- | --- |
| iPhone 17 | `ip17.jpg` |
| iPhone 16 | `ip16.jpg` |
| PlayStation 5 Slim | `ps5s.jpg` |
| PlayStation 5 Pro | `ps5p.jpg` |
| Hollyland LARK M2 | `lark.jpg` |
| DJI Mic Mini | `djim.jpg` |
| iPhone 18 Pro Max | `ip18pm.jpg` |
| iPhone 18 Pro | `ip18p.jpg` |

`.webp` and `.png` also work (for example `ip17.webp`).

## Tips

- Use HEY Market's own photos (from their Telegram channel or shop), or official images only if HEY has the right to use them as a reseller.
- Best: a cut-out with a transparent background, saved as `.png` or `.webp`. It sits naturally on the store walls, including the dark Gaming and Create walls. On an iPhone, long-press the product in a photo and "Copy" lifts it out; remove.bg does the same on a computer.
- A plain white background also works in the product list, but shows as a white box on the store walls.
- Keep each file under 150 KB: about 800 px wide is enough. Squoosh (squoosh.app) can shrink and convert to WebP.
